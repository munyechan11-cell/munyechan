# munyechan

문예찬 (Yechan Mun) 포트폴리오 사이트의 정적 파일입니다.

- 사이트: https://munyechan.vercel.app
- `public/` 이 사이트 전체입니다. 빌드 단계가 없고, main에 올리면 Vercel이 그대로 배포합니다.
- 원본(React)은 사이트 빌더 쪽 저장소에 있습니다. 여기에는 거기서 뽑은 HTML, CSS, 글꼴, 이미지만 둡니다.
- 내용을 고칠 때는 원본에서 빌드하고 정적 파일을 다시 뽑아 `public/` 을 바꿉니다.
- 구현 도구로 AI 코딩 에이전트를 사용했습니다.
